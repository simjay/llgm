# Testing pointers

- [Testing guide](../docs/contributing/testing.md) owns validation commands, observable contracts, optional service gates, and interpretation of results.
- [Contributor code map](../docs/contributing/README.md#find-the-owning-code) identifies the relevant test files for each implementation area.
- [LongMemEval runbook](../experiments/longmemeval.md) owns the frozen answer evaluation protocol and run commands.

Keep validation instructions in those guides. Record machine prerequisites and
session results only in local notes. Available tests and preparation records do
not establish completed service checks or measured answer quality.
