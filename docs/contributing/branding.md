# Logo and brand assets

The **Return** mark is an open loop that turns inward. It suggests
recursive inspection: enter the evidence, examine what is needed, and return a
finding. The simple continuous stroke remains recognizable at small sizes.

The vectors use paths and geometric shapes, with no external font or script
dependencies. PNG wordmarks have transparent backgrounds. For inline SVG, the
monochrome mark uses `currentColor`. Each wordmark variant uses a single ink color.
In the wordmarks, the Return symbol matches the lettering's visible height.

## Use and exploration

Use the light-background wordmark on white or pale surfaces, and the dark-background
wordmark on dark surfaces. Preserve the aspect ratio and the built-in clear space.
Wordmarks use deep ink (`#16333B`) on light surfaces and pale ink (`#EDF5F4`) on
dark surfaces. Teal (`#0B796F`) is reserved for the favicon background.

Selected assets are stored in `docs/_static/brand/` and distributed under the
repository's MIT license. The README uses GitHub's theme-aware picture element,
and the documentation reuses the same wordmark and favicon.

The optional design gallery at `docs/contributing/brand-explorations/index.html`
contains six directions, including Return and Branch, a light/dark toggle, SVG
downloads, and small-size previews. Open that HTML file from a repository
checkout to review the alternatives. The gallery is excluded from the published
documentation and source distribution. It is not required to use or maintain
the selected assets.
