## Reproduction

The deterministic measurement used `make coverage`. The local-data measurement
used `tests/integration/test_longmemeval_local.py` with a separate coverage data
file. The [coverage instructions](../../development/testing.md#measuring-coverage)
own current commands and prerequisites. They measure the current checkout.

This report does not identify a recoverable source/test checkpoint for each
historical denominator. The coverage JSON records measured lines, branches and
tool metadata, but does not preserve the measured source and tests. The mutable
`runs/coverage/unit/` and `runs/coverage/local-data/` paths are not immutable
archives. Reproducing the exact historical denominator requires the corresponding
code and tests, whose complete location is not established here. Preserve the
reported measurements as historical observations rather than treating a new
`make coverage` result as a rerun of them. Future reports should identify a
retained commit or source/test archive and an immutable artifact directory.

## CI and interpretation

CI runs the deterministic measurement and uploads reports. The manual LongMemEval workflow reports its separate integration coverage. These workflow edits were validated locally but have not been dispatched on GitHub.

There is no configured global percentage gate. Coverage identifies unexecuted code. It does not judge assertion quality or establish behavior outside the exercised cases. Later measurements should retain their own date, test selection and prerequisites, so changes in the denominator remain visible.

Docstring completeness is a separate check: `python tools/check_docstrings.py` verified **1,228 / 1,228 definitions across 72 Python files** at this checkpoint, including the embedded worker. It enforces presence, not writing quality or execution coverage. The separate rendered-documentation audit verifies actual API anchors/index links. A strict Sphinx exit alone is insufficient.

The preceding review checkpoint measured 370 tests and 153 subtests, with 89.19% line and 79.77% branch coverage. The new denominator includes incremental indexing, comparison and scaling modules. Two installed-package probes also passed separately in a fresh core-only wheel installation. They are not part of the editable-install coverage denominator. The two local scaling runs are performance diagnostics, not added to these coverage measurements.
