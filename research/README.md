# Internal research

Internal research designs, dated measurements and original source material for LLGM.
This directory is not published in the documentation site or package distributions.
For the supported library, use the [documentation](../docs/index.md).

Start with the [LLGM roadmap](ROADMAP.md) for the benchmark goal, concrete
implementation suggestions and next deliverables. It is the single current
planning document. Designs and dated reports provide supporting detail.

| Directory | Contents |
|---|---|
| [Design](design/README.md) | Current research architecture, design decisions, open hypotheses and experiment plans, with the superseded technical baseline identified separately |
| [Reports](reports/README.md) | Dated implementation, validation, coverage and performance observations |
| [Sources](sources/README.md) | Preserved original research brief |

The design index identifies the current direction and historical proposals.
Implementation support is documented in the public guides. A design decision
does not establish that its implementation or evaluation is complete.
Reports retain the conditions and limitations of their original measurements.
Runnable protocols and configuration files live in [experiments](../experiments/README.md).
